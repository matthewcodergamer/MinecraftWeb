# Minecraft Java 26.1 asset mirror

This directory is populated from the complete `PrismarineJS/minecraft-assets/data/26.1` tree by `.github/workflows/sync-java-26-1-assets.yml`.

MinecraftWeb resolves these local files first. Runtime Java systems translate the mirrored GUI, block/item, environment, celestial, entity, font and metadata assets into the Three.js voxel/runtime systems. The upstream PrismarineJS raw path remains an availability fallback while a fresh mirror is being deployed.
